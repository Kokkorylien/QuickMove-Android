# 文件快搬

一个独立的原生 Android 文件搬运工具，最低 Android 7.0（API 24），与 PixEz 使用相同的最低系统版本。包名 `com.kokkorylien.quickmove`，版本 1.1.0。无网络权限、广告或账号系统。可直接覆盖安装 1.0.0，保留收藏和一键任务。

[下载安装包与校验文件](https://github.com/Kokkorylien/QuickMove-Android/releases/latest) · [安装说明](安装说明.md)

## 功能

- 批量复制、剪切文件或文件夹，源路径可来自多个目录和存储介质。
- 浏览内部存储、TF/SD 卡和系统识别的可移动存储，支持当前目录筛选、全选、反选、新建目录。
- 收藏常用路径，直接设为目标，或浏览其中的目录和文件名称。
- 将源路径、目标路径和搬运方式保存为“一键任务”，执行并确认即可复用。每次读取路径当时的内容。
- 同名文件自动编号保留两份，同名目录合并；不覆盖已有文件。
- 后台和锁屏搬运：前台服务、常驻进度通知、CPU 唤醒锁，以及电池优化授权入口。
- 通知栏可暂停；中断后保留进度。继续时跳过已记录的成功文件，未完成文件从头重新复制。
- 默认先统计文件总量，显示任务总大小、整体百分比和文件数，通知栏也显示整体进度；统计阶段明确显示“正在统计总量”。可关闭“先统计总量”来使用原有的快速开始方式。
- 对目标文件和文件夹的 emoji 可选下划线（默认）、剔除、离线英文名称（可选首字母大写），或保留原名。保留中文、普通空格和扩展名；处理后出现同名文件仍保留两份。
- 改名记录显示实际源路径和目标路径，包含 emoji 处理和重名编号，可在进度卡片中查看、导出。任务完成后仍保留最近任务的记录。

## 示例：Download 搬到 TF 卡

1. 允许存储权限；Android 11 及以上打开“所有文件访问权限”。Android 7–10 写入外置卡时，在路径浏览中点击“授权存储卡”，选择卡的根目录。
2. 选择内部存储，在 `Download` 左侧勾选整文件夹，加入所选。
3. 选择外置卡，进入其根目录，点击“使用此目录”。生成的位置是 `存储卡/Download`。
4. 选择剪切或复制，按需先点击“存为一键任务”。点开始搬运并确认。
5. 在“后台运行设置”中允许忽略电池优化；部分厂商还需将 APP 设为“不受限制”、允许后台运行。通知权限也建议开启。

剪切完成会删除空的源文件夹；下次一键任务需等待系统或用户重新创建该源路径。一键任务卡片有明确的“删除任务”按钮，收藏可长按删除，仅删除配置。

一键任务也保存总量统计和 emoji 处理选项。升级后的旧任务默认开启统计和下划线处理，原路径、方式和任务 ID 保持不变。

## 搬运行为与边界

开启总量统计时，会先完整遍历源目录并读取元数据，不读取文件内容；文件很多或介质响应慢时，开始前会有额外等待。统计和搬运依次进行，启动前台服务不代表文件已经开始写入。取消勾选可跳过统计，立即搬运，但不会显示未知的总量和百分比。续传时把已完成文件的记录纳入分子与分母，跨介质已搬走的源文件也计入整体进度。源目录在执行中发生增删时，统计快照可能改变，请尽量避免同时修改源目录。

同一介质可以直接重命名移动时，优先使用原生移动，避免复制整棵目录；开启 emoji 处理时，目录整体移动必须确认内部名称也不需处理，避免跳过嵌套文件名。快速模式不为此单独预扫描，必要时改用逐项移动。跨介质使用 1 MiB 缓冲顺序搬运。每个目标目录共享一次内容索引，不为每个文件重新查询目录。

跨介质文件先写入临时文件，关闭后检查字节数、目标大小及源文件是否变化，再重命名提交、记录进度，最后删除源文件。写入失败、空间不足或源文件变化时保留源文件。检查不包含再次全量读取或哈希校验。

进度记录用于恢复进程中断，不承诺断电级事务性。请勿在续传期间修改已完成文件或其源文件。极少数在“完成重命名、尚未记录进度”时中断的文件，继续时可能生成保留副本，源文件不会因该窗口而提前删除。同名文件不执行覆盖。

emoji 处理发生在写入目标前，不修改保留的源名称。下划线/剔除后名称为空或只剩扩展名时补 `_`，避免无效路径。英文名称数据与 PixEz 定制版本使用相同的 Unicode 18 英文短名称，共 3,972 条归一化序列，离线读取，不依赖手机系统字体和 Unicode 版本。数据许可见 `third_party/unicode/LICENSE`，实现为独立的 Java 匹配器。

锁屏搬运受系统策略约束：强行停止、拔卡、部分厂商清理后台会中断，重新打开可继续。Android 15 及以上对 `dataSync` 前台服务有后台时限（通常每 24 小时共 6 小时），到限会保存进度并暂停，需打开 APP 继续。此应用不能绕过系统强制停止。

“根目录”指内部共享存储或存储卡根目录，不是 Linux 系统 `/`。不提供 root 权限，不访问其他 APP 私有目录或受限制的 `Android/data`、`Android/obb`。兼容的实际读写能力仍取决于存储介质、系统和目录授权。FAT32 等文件系统的单文件大小限制仍然适用。

## 构建

使用 JDK 21、Android SDK 36、Gradle 9.3.1、Android Gradle Plugin 9.1.0；应用不含第三方运行依赖或原生库。单个通用 APK 支持各 CPU 架构。

在 `local.properties` 配置 SDK 路径。在忽略的 `signing.properties` 中配置自己的签名（以下为示例值）：

```properties
storeFile=C\:/private/quickmove-release.jks
storePassword=YOUR_STORE_PASSWORD
keyAlias=quickmove
keyPassword=YOUR_KEY_PASSWORD
```

运行 `build.ps1`。脚本限制 4 个逻辑核心、Gradle 2 个工作线程和 1.5 GiB 堆内存，使用低优先级单次构建进程，任务结束退出。脚本中的 JDK 路径按本机修改。签名文件和密钥不要提交。

## 验证

`test.ps1` 执行桌面文件系统集成测试及任务/进度持久化测试；`build.ps1` 同时执行 Android Lint。测试用的 org.json 来自 Maven Central，仅用于 JVM 测试，不打入 APK。

当前验证记录见 [docs/VALIDATION.md](docs/VALIDATION.md)。用户已确认 1.0.0 的搬运操作有效，并反馈 emoji 目标名称问题。1.1.0 的总进度与 emoji 修复已做内部回归，仍需原 TF 卡场景复测；当前无 adb 设备连接，不能称为新版本已通过实卡验收。
